# 制作流程

共用设计约束见 [SKILL.md](../SKILL.md)，字段和引擎接口见 [接入约定](integration.md)，成品要求见 [交付规范](delivery-spec.md)。

## 城市物料：material_generation

流程：确认需求 → 设计生成 → 独立审核 → 查看结果。

### 确认需求

网站负责城市/网区/项目归属、权限、模板推荐和有效性判断。推荐同网区、同项目下已发布且有效的最新发布版本；Skill 使用网站选定的项目模板 ID、确切版本和完整配置，不扫描目录选“最新”。确认后锁定版本，下架/失效任务是否可继续由网站判定。

城市仅覆盖 `title`、`subtitle`、`qr`；未提供则继承默认值，显式清空只适用于非必填字段。主标题空白返回 `TITLE_REQUIRED`。主视觉、日期地点、版式、字体、字号、颜色和其他固定内容锁定；越权字段返回错误，不能静默忽略。

只处理网站传入的已选规格：按类型分组、多选预设、自定义尺寸、可新增类型，全部 mm、保留小数和方向。预设目录、数量及尺寸上限由网站维护，不另造默认清单。二维码链接/图片模式互斥；图片模式缺适配时保留输入并返回缺口，不猜链接或放占位图。

### 设计生成与审核

1. 合并允许的覆盖内容，记录模板、规则、素材版本；按每个规格使用实际字体排版。
2. 检查超容量、组件边界和不适配问题。城市只能精简可编辑文案或重选规格；锁定内容导致失败时交回网区，不自行改版式或主视觉。
3. 按交付规范生成 100 PPI 候选 PNG；内部记录素材清晰度提示（不足或未核实均不阻止导出）、实际路径、尺寸及 SHA-256。内部 SVG 预览不交付。
4. 将需求、模板、规则、布局与实际文件交独立审核，并保留生成流程自己的交付检查结果。未执行的检查不写通过。

逐规格在生成流程中展示预览、文件状态、尺寸、问题及下一步；PNG 交付检查和审核通过后，仅交付最终 PNG 图片。预览、配置、素材及检查报告保留在内部。失败规格保留诊断预览，其他规格的结果保留。重复规格仍按独立 `item_id` 返回。修改标题、副标题或二维码后，对受影响规格重新生成和审核，不切换绑定模板版本。网站保存/历史接口缺失时仅返回真实本地位置。

## 网区模板：template_authoring

流程：上传主视觉 → 选择版式 → 模板生成 → 预览确认 → 发布资产。

### 素材与版式

读取真实主视觉、所属网区/项目和制作者引用；无网站上传接口时做本地草稿，不宣称入库。合成海报中已有的文字/Logo 不自动视为可替换内容，需要无字主视觉或可编辑素材时明确指出。

制作者选择 S/M/L/XL、horizontal/vertical 和验收规格；可提出候选，但未确认不能当作定稿。不使用任意 JSON 参数绕过尚未支持的版式。

定义默认文案、二维码、固定内容及附加必填项。城市可编辑范围仍仅标题、副标题、二维码。验收规格不作为禁止城市自定义尺寸的白名单；不适配时返回问题。

### 生成与确认

内部保存可复用配置、素材引用、验收规格的候选 PNG 与检查结果，供模板复用和网站接入；最终图片交付仅提供通过检查的 PNG。内部配置包含：

- 模板 ID/版本、网区/项目归属、主视觉、品牌素材和规则版本。
- 版式/品牌排列、默认内容、必填字段、可编辑及锁定字段。
- 验收规格、城市尺寸策略、交付标准引用。
- 网站状态、发布时间、有效性策略及制作者确认记录。

网站未分配 ID 时使用明确的本地草稿标识；修改已发布模板由网站分配新版本，不覆盖历史。候选文件按交付规范检查并交独立审核；组件或能力缺失时保留草稿和缺口。

制作者查看实际预览、导出状态和审核结果后，确认对应模板版本、素材、规格及文件。主视觉、版式、默认内容、编辑限制等影响画面的内容改变后，重新生成、审核并确认。草稿比例回退、裁切及可读性要根据实际画面判断，不编造视觉通过。

### 发布

用户明确授权发布、确认记录和报告对应当前版本、必要检查完成且网站鉴权通过后，调用真实发布能力，不新增审批人、不重复请求同一授权。

- 网站返回成功及正式 ID、版本、发布时间：记录 `published`。
- 网站拒绝或失败：保留草稿和错误，按真实接口规则处理，不反复提交结果未知的请求。
- 无发布接口：内部保留本地配置、素材、候选 PNG 及待接入项，不记录已发布；仅将通过交付检查和审核的最终 PNG 图片提供给用户。

上传和发布时间分开记录，后续推荐使用网站发布时间。安装、部署或发布不能仅因读取了本 Skill 自动执行。
